# 算法

## 二分查找
> 适用于：==有序数组==，查找值
> 实现思路：取数组首尾俩个角标left right，取数组中间角标m(对首尾角标和取半的整数)。如果target值小于中间值，则left=m+1，否则right=m-1，或者返回m

**java实现**
```java
public static int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        int m;
        while (left <= right) {
            m = (left + right) / 2;
            if (nums[m] == target) {
                return m;
            } else if (nums[m] < target) {
                left = m + 1;
            } else {
                right = m - 1;
            }
        }
        return -1;
    }
// 改进版

```

```go
func search(nums []int, target int) int {
	for left, right := 0, len(nums)-1; left <= right; {
		m := int((left + right) / 2)

			return m
		} else if nums[m] < target {

		} else {
			right = m - 1
		}
	}
	return -1
}
```

## 二分查找 ---- LeftRightmost
> 对于要查找的target在数组中存在多个相同的值，找到这些相同值最小或最大的下标

> 思路：依旧使用二分查找，如果没有达到停止的条件，哪怕找到了目标值也不停止查找，使用一个变量记录target下标继续执行二分查找

```java
// 查找最靠左的索引
public static int searchLeftMost(int[] nums, int target) {
        int candidate = -1;
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int m = (left + right) / 2;
            if (nums[m] == target) {
                // 记录当前target下标
                candidate = m;
                // 缩小边界，准备下次查找
                right = m - 1;
            } else if (nums[m] < target) {
                left = m + 1;
            } else {
                right = m - 1;
            }
        }
        // 返回查找到的最后一个target下标
        return candidate;
    }
```
